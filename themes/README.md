# Bundled themes

These are the color themes shipped with [btop](https://github.com/aristocratos/btop)
v1.4.7, copied unmodified from
[`themes/`](https://github.com/aristocratos/btop/tree/v1.4.7/themes) in that
release. They are embedded into the ebtop binary at build time, so ebtop has
them even where btop isn't installed.

btop is Copyright 2021 Aristocratos and contributors, and is licensed under
the Apache License, Version 2.0 (see [LICENSE-APACHE](../LICENSE-APACHE)).
Individual themes credit their authors in the comments at the top of each
file.

To update them, replace the files with those from a newer btop release and
update the version above. Installed or user btop themes with the same name
take precedence over these at runtime.
